<b><h1>Rust Notitie App</h1><b>
<h2>Installatie</h2>
<p>Om deze applicatie te installeren kan de github repository gecloned worden</p>

<h2>Opstarten</h2>
<p>Het opstarten van de app kan gedaan worden door een terminal te openen en naar de /src folder te gaan</p>
<h3>Visual Studio Code (Microsoft)</h3>
	<ol>
		<li>Bovenin in VSCode staat er een kopje "Terminal", klik hierop.</li>
		<li>Klik daarna op "New Terminal".</li>
		<li>Na het openen van een nieuwe terminal opent een vlak onder in het scherm, voer hier "cd src" in.</li>
			<p>(Check hierbij dat de locatie van de terminal (de C:\Users\...\ in het project geopend staat).</p>
		<li>Nadat je in de "Rust_Notitie_App/src" folder zit voer je "cargo run" in.</li>
			<p>(Dit voert alle updates uit en download alles wat nodig is voor de uitvoering van de applicatie).</p>
		<li>Veel plezier!</li>
	</ol>
<h3>RustRover (JetBrains)</h3>
	<ol>
		<li>Open het project.</li>
		<li>Dubbelklik het main.rs bestand.</li>
		<li>Nadat het bestand geopend is verschijnen er opties rechtsbovenin het scherm.</li>
		<li>Klik daarna op het groene pijltje (Lijkt op een "Play" knop).</li>
		<li>Veel plezier met de notitie app!</li>
	</ol>
